# ストア用スクリーンショット

Google Play / ストア掲載に使う、実画面のスクリーンショット一式。
本物の画面に説明用のサンプルデータ（架空の材料・作品・価格）を入れて撮影している。

| ファイル | 画面 | 内容 |
| --- | --- | --- |
| `01-home.png` | ホーム | 作品一覧・実質時給・利益・赤字警告 |
| `02-price-sim.png` | 価格シミュレーション | スライダー・手取り/利益率/実質時給・価格の逆算（Pro） |
| `03-materials.png` | 材料管理 | まとめ買いから1単位あたりの原価を自動計算 |
| `04-templates.png` | テンプレート | 定番の作品構成を保存して新規作品をすぐ作成（Pro） |
| `05-work-edit.png` | 作品の編集 | 原価の内訳（材料費・梱包費・送料 など） |

- サイズ：幅1080px前後・9:16（スマホ縦）。Play Console にそのまま登録可。
- 価格・手数料は説明用のサンプル値（実際の手数料は各サービスの最新規約を確認）。
- 申請には最低2枚必要。4〜5枚あると訴求が安定する。

## 再生成のしかた

ローカルで `npm run dev`（または `npm run preview`）を起動し、ヘッドレスブラウザで
各画面（`/#/`、`/#/work/<id>/sim`、`/#/materials`、`/#/templates`、`/#/work/<id>`）を
スマホ相当のビューポートで撮影する。`localStorage` のキー `hmcc.appdata.v1` に
サンプルの `AppData`（`isPro: true`）を流し込んでから読み込むと、Pro機能を含む
画面を撮影できる。
