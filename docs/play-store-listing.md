# Google Play ストア掲載情報（ドラフト）

計画書「8. マーケティング計画」に基づくストアリスティングの素案。
公開前に各販売サービスの手数料表記など最新情報を確認すること。

## アプリ名（タイトル・最大30文字）

```
ハンドメイド原価計算 価格と利益
```

代替案：
- `ハンドメイド 原価計算・価格設定`
- `作品の価格計算 ハンドメイド原価`

## 短い説明（最大80文字）

```
材料費・制作時間・手数料から、赤字にならない価格と実質時給をかんたん計算
```

## 詳しい説明（最大4000文字）

```
作品の値段、なんとなく決めていませんか？

「ハンドメイド原価計算」は、アクセサリー・レジン・布小物・編み物・キャンドルなどを
制作・販売するハンドメイド作家のための、価格・利益の計算アプリです。
材料費・制作時間・販売手数料を入力するだけで、赤字にならない価格と「実質時給」が
すぐに分かります。

■ こんな悩みを解決します
・まとめ買いしていて、作品1点あたりの材料費が分からない
・制作時間を価格に入れておらず、売れても実質時給がとても低い
・販売サイトの手数料・送料・梱包費・委託料まで計算できていない
・「原価の2倍」「周りと同じ」など、なんとなくで価格を決めている

■ 主な機能
・材料管理：購入価格・量・送料から1単位あたりの原価を自動計算
・作品ごとの原価計算：材料費＋制作時間＋梱包費＋その他経費
・価格シミュレーション：価格を動かすと利益・利益率・実質時給がその場で変化
・価格の逆算：赤字にならない最低価格／目標時給を確保できる価格を提案（Pro）
・販売方法の比較：オンライン・対面・委託・オーダーの手取りを比較（Pro）
・テンプレート複製・CSV出力・端末内バックアップ

■ 端末内で完結・安心
データはお使いの端末の中だけに保存され、外部に送信されません。
バックアップの書き出し／復元にも対応しています。

■ 料金
・無料：作品3点・材料20点まで、基本の原価・利益計算（広告あり）
・Pro（買い切り500円／1回のみ）：作品・材料が無制限、価格逆算、販売方法の比較、
  テンプレート、CSV出力、広告なし。月額・年額の継続課金はありません。

作品の値段を、感覚ではなく数字で決めましょう。

※ 本アプリは価格・利益の試算ツールです。税務・会計・法的な助言を行うものではありません。
　 手数料率や送料は各販売サービスの最新規約をご確認ください。
```

## キーワード方針（タイトル・説明・スクショに反映）

計画書 8.1 の具体キーワード：

- ハンドメイド 原価計算
- 作品 価格計算
- 販売価格 利益
- ハンドメイド 値段 決め方
- 材料費 計算
- 実質時給

## カテゴリ / 連絡先

- カテゴリ：ビジネス（または仕事効率化）
- コンテンツのレーティング：全年齢
- プライバシーポリシー：端末内保存・外部送信なしを明記（要URL）

## スクリーンショット案（計画書 5. 画面構成に対応）

1. ホーム：作品一覧と赤字警告（「○件が赤字です」）
2. 価格シミュレーション：スライダーで実質時給がリアルタイムに変化
3. 価格の逆算：「赤字にならない最低価格」「目標時給を確保できる価格」
4. 販売方法の比較：オンライン／対面／委託／オーダーの手取り比較表
5. 材料管理：単位原価の自動計算

各スクショに訴求コピーを重ねる（例：「3,000円で売っても実質時給500円？」）。

## データセーフティ申告（Play Console）

- データ収集：なし（すべて端末内 localStorage に保存）
- データ共有：なし
- アプリ内購入：あり（買い切り500円のProロック解除）
- 広告：無料版に表示（AdMob を利用する場合は広告目的のデータ利用を申告）
